# Pet Management App

## Purpose
Manage and update pet information efficiently

## Live URL
CLient Live Link : https://petnest-client-rho.vercel.app
Server Live Link : https://petnest-server-beige.vercel.app

## Features

- Add and update pet details including name, breed, age, location, and image
- Real-time toast notifications for user feedback
- Responsive design with Tailwind CSS
- Dynamic routing for individual pet updates
- Modern UI with HeroUI components
